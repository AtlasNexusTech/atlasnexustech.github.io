Atlas Labs: ATLAS

A coalition of agents, not a single agent

ATLAS is a distributed cognitive architecture, open source (MIT). Instead of one agent doing everything, a coalition of specialized agents collaborates: each has a role, a partial view, and a mandate to check the others.

The goal: better decisions, faster execution and memory continuity across tasks. All on your infrastructure, with replaceable components.

See the code on GitHub Back to Labs

The principle

Why a coalition?

🧭

Roles, not duplicates

Each agent covers a precise domain: coordination, governance, validation, synthesis, infrastructure, memory. No agent does everything, each excels on its scope.

🛡️

Cross-validation

One agent decides, another criticizes. The coalition treats contradiction as a mandatory step, not a luxury: that's what separates a team decision from an isolated opinion.

🧠

Shared memory

Memory (MNEMOSYNE) spans tasks and agents: nothing is lost between sessions, past decisions feed the next ones.

The coalition

The six agents

H

HERMES

Coordination

The conductor. HERMES receives the goal, breaks it into subtasks, distributes them to the right agents and arbitrates conflicts. It keeps the course when agents diverge.

A

ATHENA

Governance

The rule keeper. ATHENA checks that every action respects the scope, constraints and permissions. It says no when needed, before the system regrets it.

Æ

AEGIS

Critical validation

The devil's advocate. AEGIS attacks proposed decisions: inconsistencies, biases, blind spots, risks. A decision that leaves the coalition survived its critique, not just its intuition.

Δ

DELPHI

Synthesis

The information gatherer. DELPHI collects data, sources and opinions, then produces a structured synthesis the other agents can consume. Without it, each agent would work with an incomplete picture.

Φ

HEPHAESTUS

Infrastructure

The hands of the coalition. HEPHAESTUS executes: tools, APIs, files, deployments. While other agents think, it acts concretely on your infrastructure and reports the result.

M

MNEMOSYNE

Memory

The long-term memory. MNEMOSYNE stores, structures and recalls what the coalition learned: past decisions, mistakes, preferences. It makes the system smarter with every use.
