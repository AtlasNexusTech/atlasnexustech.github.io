Atlas Labs : ATLAS

Une coalition d'agents, pas un agent

ATLAS est une architecture cognitive distribuée, open source (MIT). Au lieu d'un agent unique qui fait tout, une coalition d'agents spécialisés collabore : chacun a un rôle, une vue partielle, et un mandat de vérification sur les autres.

L'objectif : des décisions de meilleure qualité, une exécution plus rapide et une continuité de la mémoire entre les tâches. Le tout sur votre infrastructure, avec des composants remplaçables.

Le principe

Pourquoi une coalition ?

🧭

Des rôles, pas des doublons

Chaque agent couvre un domaine précis : coordination, gouvernance, validation, synthèse, infrastructure, mémoire. Aucun agent ne fait tout, chacun est excellent sur son périmètre.

🛡️

Une validation croisée

Un agent qui décide, un autre qui critique. La coalition intègre la contradiction comme étape obligatoire, pas comme un luxe : c'est ce qui distingue une décision d'équipe d'une opinion isolée.

🧠

Une mémoire partagée

La mémoire (MNEMOSYNE) traverse les tâches et les agents : rien ne se perd entre deux sessions, les décisions passées nourrissent les suivantes.

La coalition

Les six agents

H

HERMES

Coordination

Le chef d'orchestre. HERMES reçoit l'objectif, le décompose en sous-tâches, les distribue aux agents compétents et arbitre les conflits. C'est lui qui maintient le cap quand les agents divergent.

A

ATHENA

Gouvernance

La gardienne des règles. ATHENA vérifie que chaque action respecte le périmètre, les contraintes et les permissions définies. C'est elle qui dit non quand il le faut, avant que le système ne le regrette.

Æ

AEGIS

Validation critique

L'avocat du diable. AEGIS attaque les décisions proposées : incohérences, biais, angles morts, risques. Une décision qui sort de la coalition a survécu à sa critique, pas seulement à son intuition.

Δ

DELPHI

Synthèse

Le rassembleur d'information. DELPHI collecte les données, les sources et les avis, puis produit une synthèse structurée que les autres agents peuvent consommer. Sans lui, chaque agent travaillerait avec une vision incomplète.

Φ

HEPHAESTUS

Infrastructure

Les mains de la coalition. HEPHAESTUS exécute : outils, API, fichiers, déploiements. Là où les autres agents pensent, il agit concrètement sur votre infrastructure et rend compte du résultat.

M

MNEMOSYNE

Mémoire

La mémoire longue. MNEMOSYNE stocke, structure et rappelle ce que la coalition a appris : décisions passées, erreurs, préférences. C'est elle qui rend le système plus intelligent à chaque usage.

Open source, testé, itéré

ATLAS suit la même logique que tout l'écosystème Atlas Nexus : chaque projet est testé, itéré et ouvert avant de devenir un produit déployé. Le code est public, les limites sont documentées.
